# ws-minigraph : a pangenome graph mapper

We replaced the original minimizer sampling with weighted syncmer sampling for pangenome graph and implemented the second sampling for repetitive regions in the original code of [minigraph]( https://github.com/lh3/minigraph ) as well as anchor generation after second sampling.

# Compile

Please first download the code from the repository and enter the command in the console:

```
make
```

Then it can be used.

## Usage example

The following command line example is recommended for experiments based on the PacBio dataset:

```
./minigraph -k 19 --syncs 15 --synct 3 -W meryl-file.txt pangenome-graph.gfa reads.fq > output.gaf
```

For experiments based on the ONT dataset, it is recommended to:

```
./minigraph -k 15 --syncs 11 --synct 3 -W meryl-file.txt pangenome-graph.gfa reads.fq > output.gaf
```

If you do not have the file generated by [Meryl](https://github.com/marbl/meryl), please download and compile the Meryl tool first, and use the following command-line example to use Meryl to generate the s-mer frequency file corresponding to the input - W parameter:

```
./meryl count k=15 output merylDB pangenome-graph.gfa
./meryl print greater-than distinct=0.9998 merylDB > meryl-file.txt
```

or

```
./meryl count k=11 output merylDB pangenome-graph.gfa
./meryl print greater-than distinct=0.9998 merylDB > meryl-file.txt
```

Note that the value of parameter **k** entered for running the meryl tool should be equal to the value of parameter **syncs** (the length of s-mer)entered for running ws-minigraph.
